## 🔄 How It Works

### User Flow
```
1. User opens index.html
2. Shows login page
3. User selects role (Member/Librarian)
4. User enters credentials (or clicks demo)
5. System validates login
6. Appropriate dashboard loads
7. User navigates using sidebar
8. Pages load dynamically
9. User interacts with features
10. Data updates in real-time
```

### Data Flow
```
Input → Validation → Processing → Display → Persistence
  ↓         ↓          ↓          ↓          ↓
Form    Check type  Calculate  Render HTML  Save to
Input    & format   results    to page    localStorage
```

## ❓ FAQs

**Q: Do I need a web server?**
A: No, you can open index.html directly in a browser. For production, use a web server.

**Q: Will data persist after refresh?**
A: Yes, data is stored in browser's localStorage.

**Q: Can I use this with a real database?**
A: Yes, the architecture supports API integration (see DEVELOPER_GUIDE.md).
